Moreover, after each round, the LLM-generated code artifact was evaluated against security and inclusivity criteria by 13 human experts and five LLM-based reviewers using a rubric-based assessment. The results demonstrate that an increase in the specification detail improves the inclusivity of LLM-generated code without causing any negative impact (trade-offs) on security.
